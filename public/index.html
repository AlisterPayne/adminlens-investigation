Why is this CSV export necessary?

Google’s Directory API only returns applications with currently active user tokens, and the Reports API automatically purges audit logs after 180 days. Furthermore, Google does not expose a public Admin SDK endpoint for the App Access Control table—meaning even automation tools like GAM 7 cannot query this data directly.

Exporting the list from the Google Admin Console provides the permanent domain baseline, allowing Admin Lens to discover dormant sanctioned apps, OU-level trust overrides, and restricted scopes that would otherwise be completely invisible.

Step-by-Step Export Instructions
1
Navigate to App Access Control in Google Admin Console Open Console ↗

Sign in to admin.google.com as Super Admin. In the left navigation, go to:
Security > Access and data control > API controls > App access control > Apps tab

2
Download the Application List as CSV

In the upper right corner of the applications table, click the Download list icon (📥) and choose Comma-separated values (.csv).

Google will generate a file containing App Name, Client IDs, Verification Status, Access (Trusted/Limited/Blocked), and Scope lists.
3
Import File into Admin Lens

Save the exported file as owl_apps.csv in your Admin Lens project folder, or simply drag and drop the CSV into the upload area below.
